# مدير حساب X (Next.js + twitterapi.io)

تطبيق شخصي للنشر على Vercel: حذف التغريدات بفلاتر، إدارة من تتابعهم، وإرسال رسائل خاصة.

## الإعداد على Vercel
1. استورد المستودع في Vercel (Framework: Next.js).
2. أضف متغيرات البيئة من `.env.example` (**لا تضع المفاتيح في الكود**):
   - `TWITTERAPI_IO_KEY`, `TWITTERAPI_IO_BASE_URL`
   - `APP_PASSWORD`, `SESSION_SECRET` (نص عشوائي طويل) لحماية التطبيق
   - `X_USERNAME`, `X_EMAIL`, `X_PASSWORD`, `X_TOTP_SECRET`, `X_PROXY`
3. افتح التطبيق، وسجّل الدخول، واضغط **تسجيل دخول X** ثم انسخ الـ cookie إلى `X_LOGIN_COOKIE` وأعد النشر.

## ملاحظات مهمة
- عمليات الكتابة (حذف/إلغاء متابعة/رسالة) تتطلب `login_cookie` وبروكسي سكني؛ تسجيل الدخول $0.005 والحذف $0.002 لكل عملية.
- الحذف الجماعي يعمل من المتصفح تدريجياً (مع تأخير وإعادة محاولة عند 429)؛ أبقِ التبويب مفتوحاً.
- غير متاح عبر هذه الـ API: حذف/حظر متابع، قراءة الرسائل الخاصة أو حذفها.
- حدّد تاريخاً أو أي فلتر من تبويب التغريدات، ثم **فحص** ثم **حذف المحدد**. بدون فلاتر = حذف كامل.

## الوركر (إزالة المتابعين + المهام الطويلة)
مجلد `worker/` يعمل على سيرفرك (مثلاً Oracle Ubuntu). يستلم المهام من Upstash Redis ويزيل المتابعين عبر خيار X الأصلي **Remove this follower** باستخدام متصفح آلي (Playwright).

1. أنشئ قاعدة Upstash Redis مجانية وضع `UPSTASH_REDIS_REST_URL/TOKEN` في Vercel وفي `worker/.env`.
2. على السيرفر: `git clone` ثم `cd X_delet/worker && ./install.sh`، عدّل `.env` (ضع كوكيز `auth_token` و`ct0` من متصفحك) وأعد تشغيل السكربت.
3. ابدأ بـ `DRY_RUN=1` (يتحقق من ظهور الخيار دون إزالة أي أحد)، راقب `journalctl -u x-worker -f`، ثم احذف السطر.

**إجراءات الأمان:** سقف يومي (40)، تأخير عشوائي 45–120 ثانية، استراحة طويلة كل 10، توقف تلقائي عند طلب تحقق/تقييد أو 3 إخفاقات متتالية، استئناف بعد إعادة التشغيل، وإمكانية الإلغاء من الواجهة.
> أتمتة المتصفح غير رسمية وتخالف شروط X؛ يبقى خطر تقييد الحساب قائماً وإن كان مخفّفاً. لم تُجرَّب المحددات (selectors) على X الحقيقي بعد، لذلك ابدأ بـ DRY_RUN.

## الحذف الآمن للتغريدات
نسخة احتياطية JSON إلزامية قبل الحذف، قائمة تغريدات محمية، تأكيد بالكتابة عند أكثر من 20 تغريدة، وتأخير بين العمليات مع إيقاف فوري.
